## Project Summary
**AR Perspective Assist** is an Android Augmented Reality (AR) mobile application developed in **Unity 6 (`6000.6.9f1`)** using **C#**, **AR Foundation**, **Google ARCore**, and custom **HLSL shaders**. It helps students and beginners practice perspective drawing by anchoring adjustable **1-Point** and **2-Point** 3D perspective grids onto horizontal drawing surfaces or vertical walls (**Snap Wall**), alongside a surface-anchored **Trace Photo** mode with real-time GPU white-background removal (**Clear White**).

- **System Source Code Repository:** https://github.com/ANTHONY19-spec/ar-perspective-assist-system
